# Submission checklist

Carried over from the original README. The official rules live in [RULES.md](RULES.md) once exported
from Notion; where the two disagree, the rules win.

- [ ] Devpost submission by **10:00 AM EST Sun Oct 11**, exactly one project per team
- [ ] Public **GitHub link** to all code written for the hack
- [ ] **Demo video, 2 minutes max**, mentioning sponsor tech (Photon Spectrum, Gemini, Nessie)
- [ ] Track: **Beginner / General**, plus up to 4 prizes:
  - Best iMessage Agent with Photon (must integrate Spectrum — `spectrum-ts`, via `core/plugins/platforms/photon`)
  - MLH Best Use of Gemini API
  - Capital One Best Use of Nessie
- [ ] Someone at the table 12:00–1:30 PM for judging (4 minutes per judge: 2-minute demo, 2 minutes Q&A)
- [ ] No cross-posting

## Open question for the team

The original checklist said "nothing built before hacking started". `core/` is a vendored open-source
runtime that predates the hackathon. Using open-source libraries and frameworks is normally allowed when
disclosed, and the README discloses it, but check RULES.md and ask an organizer if it is unclear.
